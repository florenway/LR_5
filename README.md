# Нижняя навигация

Практическая работа.  
Волошенко Кирилл Андреевич, группа Т-433901-ИСТ.

В приложении три экрана, переключение через нижнюю панель.

1. Форма обратной связи. Поля ФИО и email, кнопка «Отправить». После нажатия поля очищаются и открывается окно с данными заявки.
2. Тестирование. На экране вопрос и кнопка «Ответить». В окне нужно выбрать вариант, результат показывается всплывающим сообщением.
3. Уведомления. Кнопка с колокольчиком отправляет уведомление с ФИО и номером группы.

Иконка на рабочем столе своя, с инициалами ВК.

## Запуск

Нужны Android Studio и JDK 17.

1. File → Open и выбрать эту папку.
2. Дождаться синхронизации Gradle.
3. Запустить на телефоне или эмуляторе (API 26 и новее удобнее).
4. На экране «Уведомления» при первом нажатии система спросит разрешение. Без него пуш не появится. На Android 13 и новее это обязательный запрос.

Поля формы уже заполнены моими данными, их можно стереть и ввести заново.
